# Contributing

Issues and pull requests are welcome.

- Run `test/selftest.sh` before opening a pull request. It needs no network or API key.
- New agent or provider examples go in `examples/`, read secrets from environment variables, and
  never hard-code a key or a personal path.
- Results tables in the README name the model, where it ran and the agent, and come from runs you
  did, with the per-run seconds as printed.
